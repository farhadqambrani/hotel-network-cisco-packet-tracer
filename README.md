# Hotel Network Configuration using Cisco Packet Tracer

## Overview

This project demonstrates the design and implementation of a secure and scalable hotel network using Cisco Packet Tracer.

The network uses VLANs for departmental traffic segmentation, inter-VLAN routing for communication between different network segments, and DHCP for automatic IP address allocation. Security measures such as password protection and Access Control Lists (ACLs) are also implemented.

## Objectives

* Design a scalable hotel network infrastructure
* Implement VLAN segmentation for different departments
* Configure inter-VLAN routing
* Configure DHCP for automatic IP address allocation
* Implement network security using ACLs and password protection
* Test connectivity and network functionality using Cisco Packet Tracer

## Network Departments / VLANs

The network includes separate VLANs for:

* Admin Office — 192.168.10.0
* Reception — 192.168.12.0
* Marketing — 192.168.13.0
* IT Department — 192.168.19.0
* Guest Floors — 192.168.15.0 and 192.168.18.0

## Key Configurations

### VLAN Configuration

VLANs are used to separate hotel departments and improve network organization, performance, and security.

### Inter-VLAN Routing

Routers are configured with sub-interfaces to enable communication between different VLANs.

### DHCP

DHCP is configured to automatically assign IP addresses to devices within the appropriate network segments.

### Network Security

Security measures include password protection and Access Control Lists (ACLs) to control traffic between VLANs.
